# 1. 使用 FastAPI 作为 Web 框架

## 状态

已接受

## 背景

需要一个 Python Web 框架实现短链接 API，要求：
- 高并发重定向；
- 自动生成 API 文档；
- 类型安全；
- 易于测试。

## 决策

使用 FastAPI。

## 理由

- 原生 async/await，适合 IO 密集的重定向场景；
- 基于 Pydantic，请求/响应校验清晰；
- 自动生成 OpenAPI 文档，方便调试和集成；
- 社区活跃，生态成熟。

## 后果

- 团队需要熟悉 async/await；
- 部分同步库需要适配或放入线程池；
- 需要额外关注事件循环阻塞问题。
